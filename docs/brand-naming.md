# Brand naming — shortlist v1 (2026-10-20)

**Goal:** a distinctive, trademarkable name (Class 3) that's Arabic-inspired, easy to say in Tamil/Hindi/English, and tells the honest story (Chennai founders, Dubai roots, alcohol-free oils). "Dubai" goes in the tagline, not the name. Avoid descriptive perfume words (oud, attar, musk, amber, saffron) — they're weak or unregistrable as trademarks.

**Checks done:** `.com` / `.co` via domain-registry lookup (Vercel), `.in` via the NIXI whois registry, existing perfume/attar brand conflicts via web search. **Not yet done:** India trademark register (Class 3) and Instagram/WhatsApp handle checks — see "Next steps".

**Recommendation:** shortlist **Nafhaar**, **Samarah**, **Rawiya** for the founder vote and customer poll; keep **Zaafira** as the reserve (both domains free).
- Nafhaar is the strongest on every check: coined (most registrable), fragrance meaning, both domains free.
- Domain plan: if the `.com` is taken, use `.in` as primary (India-first brand) plus `<name>perfumes.com` or `.co` as a redirect.

## Next steps
1. **Founders pick top 3** (you + co-founder).
2. **Trademark search (Class 3)** for the top 3 on IP India's public search: https://tmrsearch.ipindia.gov.in/eregister/ — search "wordmark", class 3, and also phonetic/similar spellings. Anything identical or confusingly similar in Class 3 (or Class 35 retail of cosmetics) → drop.
3. **Handles:** check Instagram, WhatsApp Business display name, YouTube for the exact name (and `<name>.in` / `<name>perfumes` variants).
4. **Customer poll:** 20–30 target customers/buyers (Instagram story poll + the buyer interviews) — "which name feels most premium / easiest to remember?"
5. **Register:** domain(s) immediately (cheap), then file the Class 3 trademark (₹4,500 with DPIIT/MSME status) by week 3.
